# Legal

**What goes here:** binding agreements and authority — trusts, wills, power of attorney, contracts, notarized documents, and similar.

**Placement rule:** if it creates or modifies legal obligations, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set, and the Conflict Resolution section (Legal > Finance when both could apply — e.g. a trust document that also touches account titling stays here, not under Finance).

Common subfolder pattern: a `Trust_Documents/` (or equivalent estate-planning) subfolder, with a `Reference/` sub-subfolder for the single-page excerpts institutions typically ask for (see Organization_Philosophy.md's "Intentional Duplicates" section — don't merge these with the full documents). Legal documents filed here also feed the joint Legal dashboard in the connected Living Reference folder.

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
