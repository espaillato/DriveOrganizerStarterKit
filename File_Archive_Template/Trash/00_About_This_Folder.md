# Trash

This folder is for files that need deleting but can't be deleted directly during an automated/unattended pass — see `Organization_Philosophy.md`'s "Trash / Pending Deletion" section for the full convention.

**How it works:** on a scheduled or unattended run, there's no one present to approve an interactive delete, so instead the file gets moved here with `FOR_DELETE` appended to its filename (e.g. `Old_Duplicate_Name_FOR_DELETE.pdf`). Review this folder yourself periodically and delete from here directly once you've confirmed each one.

In an interactive session, a direct delete (with your explicit approval) is also available — this folder is mainly the fallback for when no one's watching.

Delete this file once you've used this folder for its intended purpose, or leave it — it does no harm either way.
