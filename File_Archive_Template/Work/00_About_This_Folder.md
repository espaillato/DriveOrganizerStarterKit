# Work

**What goes here:** employment history — employers, pay stubs/tax forms, contracts, resume, credentials, and similar.

**Placement rule:** if it only matters because you worked somewhere, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set. Common subfolder pattern: `Employers/[Company]/`, `Credentials/[Person]/` (resume, education, certifications), `Contracts/[Counterparty]/`.

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
