# Personal

**What goes here:** non-critical reference material — travel, manuals, recipes, hobbies, entertainment, product manuals/receipts, and similar.

**Placement rule:** if losing it is annoying but not dangerous, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set. This category tends to accumulate the widest variety of subfolders — add one per topic as it warrants it (e.g. `Travel/`, `Air_Miles/`, `General/`).

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
