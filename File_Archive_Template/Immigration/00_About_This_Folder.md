# Immigration

**What goes here:** permission to enter, stay, or leave a country — visas, entry/exit records, residency applications, residency ID cards, customs declarations, and similar.

**Placement rule:** if losing it affects where you can legally live or travel, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set. That table specifically flags one decision worth making early and writing down as a rule: whether a residency card counts as Identity or Immigration for your situation — don't leave it as a recurring one-off judgment call.

Common subfolder pattern: by country, and/or by person, depending on how many countries and people this applies to in your household.

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
