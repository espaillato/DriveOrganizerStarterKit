# Unsorted

This is the inbox/staging folder — drop new, unfiled documents here (scans, downloads, exports) and `file-renamer` will read, rename, and move each one into its correct category automatically (this is the one folder where it acts without asking first — see `Organization_Philosophy.md`'s Move & Rename Authority section).

This folder should be **emptied during cleanup passes**, not used as permanent storage — see the Subfolder Semantics table's "Inbox / Staging" row. If something sits here for a while unprocessed, that's a sign to run `file-renamer` in batch mode against this folder.

**Build up gradually.** Drop a manageable batch (a few dozen files, not hundreds) and process it before adding the next — see `SETUP_GUIDE.md` step 7 for why.

Delete this file once you've used this folder for its intended purpose, or leave it — it does no harm either way.
