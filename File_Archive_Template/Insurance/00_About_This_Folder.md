# Insurance (Non-Health)

**What goes here:** risk-transfer contracts — auto, home, umbrella, liability, and similar. (Health insurance administration belongs under `Health/` instead, since a doctor/clinic relationship is the more relevant axis there.)

**Placement rule:** if it limits financial damage from adverse events, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set, and the Conflict Resolution section (Health > Insurance when a document could plausibly fit either).

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
