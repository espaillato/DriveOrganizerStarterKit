# Home

**What goes here:** physical living space — leases, utilities, HOA, maintenance, management fees, and similar.

**Placement rule:** if it changes when you move homes, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set, and the Conflict Resolution section (Home > Work when both could apply). Common subfolder pattern: one folder per property/asset, named `Property_City_State` (domestic) or `Property_City_CountryCode` (international) — see the Subfolder Semantics table for the exact naming rule.

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
