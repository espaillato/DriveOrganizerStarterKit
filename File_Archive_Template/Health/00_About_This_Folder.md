# Health

**What goes here:** medical state and care — diagnoses, labs, imaging, prescriptions, national/private health-insurance administration, and similar.

**Placement rule:** if a doctor would care about it, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set, and the Family Override Rule if this document is about a child or parent rather than a primary household member (those go under `Family/[Person]/` instead, regardless of topic).

Common subfolder pattern: by person, then by document type or year (e.g. `[Person]/Checkups/`) as volume warrants it. Health documents filed here for a tracked person also feed that person's `Health_Summary_[Person].md` dashboard in the connected Living Reference folder — see that system's own README for how the two stay in sync.

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
