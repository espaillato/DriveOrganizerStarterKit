# Identity

**What goes here:** legal proof of who you are — passport, national ID, driver's license, Social Security/national ID number, marriage certificate, police certificate, and similar.

**Placement rule:** if it proves who you are, it belongs here regardless of issuer.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set, including how Identity relates to Immigration (a residency card can arguably belong to either — decide up front and log the decision as a rule there) and the Conflict Resolution section (Identity > Immigration when both could apply).

Common subfolder patterns for this category: by person (each tracked adult's own subfolder), and a `Joint/` subfolder for documents shared across people (a marriage certificate, a joint ID record).

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
