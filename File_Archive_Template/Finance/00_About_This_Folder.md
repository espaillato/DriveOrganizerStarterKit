# Finance

**What goes here:** money, assets, and obligations — investments, retirement, bank accounts, loans, taxes, and similar.

**Placement rule:** if it affects net worth, cash flow, or taxes, it belongs here.

See `Organization_Philosophy.md`'s Category Semantics table at the File Archive root for the full rule set. Common subfolder pattern: `Institutions/` (by bank/brokerage), `Investments/`, `Net_Worth/`, and `Taxes/[Year]/`. Documents filed under Institutions/Net_Worth/Investments feed the joint Finance dashboard in the connected Living Reference folder — see that system's own README for how the two stay in sync.

Delete this file once you've filed real documents here, or leave it — it does no harm either way.
