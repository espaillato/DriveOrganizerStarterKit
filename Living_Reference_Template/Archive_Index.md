# File Archive — Index

A single at-a-glance map of the File Archive. This is **not** a full file listing — that would just duplicate the filesystem and go stale immediately. It's a curated jumping-off point: how big each category is, how current it is, where the deeper Living Reference notes already live, and a short hand-picked list of documents you're actually likely to reach for. For everything else, use the category folder link and Drive search.

Full naming/placement rules live in `Organization_Philosophy.md` at the File Archive root — this index doesn't repeat them.

## Open Filing Questions

**Home for File-Archive-only `[!agent-question]`s.** Most `[!agent-question]`s attach to the specific Living Reference note they're about (see `00_README`'s "The reverse direction"). But a pure filing/placement ambiguity in the File Archive — a file that could reasonably belong in more than one category, an "always ask" rename/move `file-renamer` can't resolve on an unattended run — often has no corresponding Living Reference note to attach to. This section is that home, so those questions surface here instead of only in a run report you might not read.

Same mechanics as everywhere else: `> [!agent-question]` / `> For [you]: <question, with the file's current location and the proposed alternative>`, resolved only by a matching `> [!user-answer]` beneath it (removes both, logs the resolution below). Any skill can write here — `file-renamer` on an unattended always-ask case, `file-archive-audit` on an ask-the-user File Archive finding. Dedup before writing.

## Quick access — documents worth linking directly

Not exhaustive — just the ones most likely to get reached for without digging through folders. Add to this as you notice yourself repeatedly hunting for the same file. Example categories to seed the idea:

**Identity / travel** — passport/ID scans, trusted-traveler program cards.

**Legal** — the page(s) institutions actually ask for out of a longer estate document (e.g. a trust's signature page).

**Finance** — a credit-card ownership list, if you have several cards across household members.

**Home** — the current lease or mortgage document.

**Individual** — this year's goals document.

**Security** — backup codes, disk-encryption recovery keys.

## What this index doesn't cover

Document your own scope decisions here as you make them — which categories get a full Living Reference summary note and an owning review, and which stay as archive-only storage with just a count and maybe a few Quick Access pins. A category with real ongoing decision-relevant state (expiring policies, active claims, open strategic questions) is a candidate for its own note and review; one that's just accumulating stable records probably isn't, and that's a fine, deliberate choice — not a gap to apologize for.
